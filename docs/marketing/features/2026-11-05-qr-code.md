# Share your booking page as a QR code

- **Shipped:** 2026-11-05 · **Published:** —
- **For:** Partners
- **PR:** #46

## In one line
Every venue gets a QR code that opens its booking page in one scan.

## What partners get
- Download the code as PNG or SVG from **Business profile**.
- A ready-to-print A4 **"Scan to book a court"** poster in the venue's own colours.
- A "QR code" option in the page's Share menu, so a customer can scan it off a screen.

## Talking points
- Put it at the front desk, on the courts, on flyers and on social posts.
- It's a short link, so the code stays easy to scan from a distance.
- Printed codes keep working even if the page address changes.
